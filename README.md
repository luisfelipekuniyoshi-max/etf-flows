# ETF Flows — BTC & ETH

Acompanhamento diário dos fluxos de capital nos ETFs de Bitcoin e Ethereum.

**Dados:** [farside.co.uk](https://farside.co.uk)
**Atualização:** automática todo dia útil às 11h BRT via GitHub Actions

## Ver o gráfico

👉 **https://luisfelipekuniyoshi-max.github.io/etf-flows/**

## Rodar localmente

```bash
git clone https://github.com/luisfelipekuniyoshi-max/etf-flows.git
cd etf-flows
pip install -r requirements.txt
python etf_flows_update.py
# abre docs/index.html no navegador
```
